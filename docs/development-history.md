## 当前功能与范围

当前已接入本地持久存储，并完成首页、轨迹、日历和近 30 天统计：

- 第一次进入先填写用户昵称，本地保存成功后进入首页；之后打开直接恢复昵称。昵称为 1—12 个字符，去掉首尾空格，空昵称或过长输入不能提交。
- 今天页左上角显示昵称，右上角是设置，标题为“今天怎么样？”。没有偏好时默认琉璃主题，开心有飞鸟与暖光、平静有水波、低落会落雨、疲惫有浓雾；主星球使用已确认的 92% 比例，选择保留软胶按压与回弹。首次未记录时显示空星球，不自动保存某种心情。
- 设置可切换“琉璃星球 / 宇宙玻璃舱”，单独保存偏好。两主题当前均可选开心、平静、低落、疲惫；生气、普通、充满动力只作为旧记录保留，保留原心情类型与日期，不强行转换。
- 点选后立即改变背景和星球，同时自动保存；不再使用大面积选择提示框和提交按钮。
- 首页导航上方的固定提示区分正在保存、已经记录和保存失败，反馈不会随内容滚出屏幕。保存失败时保留本次选择，并提供“再试一次”；读取失败时暂停新记录，避免覆盖尚未读取的数据。
- 每个设备本地日期保留一条记录，当天可反复修改；修改时保留首次创建时间。重新打开会读取历史记录，并恢复今天的心情。
- 琉璃主题四页共用浅绿、暖米色的渐变光场，随当天心情轻微着色；正文与操作色保持清晰。首页短句与真实保存状态分开显示，低落或疲惫时不催促用户改变感受。原动效样板继续保留天气说明文字。
- “轨迹”页改为心情星座：向右拖动看过去，向左看未来 7 天，星位随镜头产生缩放与前后景视差，松手后轻缓落在日期上。已记录日期显示彩色星光，相邻两天都有记录时以渐变线连接；未记录和未来日期为空心星位与淡虚线，不伪造心情、不对心情打分。也可以点星、用左右箭头或“回到今天”查看。
- 底部只显示“今天 / 轨迹”；轨迹页上方提供“日历 / 近 30 天”入口。日历和统计页保留固定的“返回轨迹”，底部仍选中轨迹；点底部“轨迹”回到星座根页。Android 返回逻辑为“日历或统计 → 轨迹 → 今天”，今天页交由系统处理，实体返回键仍待真机验证。内部沿用四条页面路由以保留现有镜头与日期浏览状态，没有新增导航依赖。
- 琉璃主题的“今天 ↔ 轨迹”使用同一颗星球与同一条往返路径，保持朝向、逐步缩小到“回到星球”入口旁；星座轻微展开，两页文字在路径中点交接。星球全程可见，取消了大幅放大、倾斜和扫屏雾层。日历、统计的琉璃主题转场仍直接切换，留待后续阶段。宇宙玻璃舱保留原观察位置与镜头节奏；底部导航在动画中仍可点击，连续操作保留最后一个目的地。系统减少动态或进入后台时直接安全落位；相关设备行为待真机验证。
- “日历”页按周一至周日排列，支持上个月、下个月和回到今天。日期格显示真实记录的心情图标；点选后在底部查看心情和首次记录时间。没有记录的日期留白，未来日期显示尚未到来；本阶段只查看，不补记或修改历史日期。
- “统计”页显示包含今天及之前 29 天的次数和简单色条。每个日期只统计最后记录的心情；没有记录的日期不加入次数，未来记录不加入范围。范围内实际存在生气、普通或充满动力的旧记录时额外显示并标注，避免漏计。

宇宙玻璃舱沿用原来的缓慢呼吸、雾层、卫星和保存波纹；琉璃主题使用已确认的天气与微景观动效。两主题在后台或系统启用减少动态时停止循环，设置页打开时暂停主星球动画。Android 点选触发一次 `Clock_Tick` 轻触觉反馈；系统行为仍待真机验收。

标签、AI 总结、桌面小组件和导出仍未实现。当前未生成 APK，也没有发布应用；Expo Go 预览或 JavaScript 打包成功不等于已经生成安装包。

## Codex 内的可操作预览

Expo Web 与 Android 复用同一入口、导航、页面、心情状态和存储逻辑。浏览器额外增加最大 430 像素的预览宽度，方便在 Codex 右侧操作。

```powershell
npm.cmd run web
```

启动后，在 Codex 浏览器面板打开终端显示的本地地址。尚未取名时先填写昵称；已保存昵称时直接进入首页。点选心情即自动记录，从“轨迹”查看星座，再进入“日历”或“近 30 天”；重新选择会同步更新当天节点、日期图标和计数。刷新后应恢复已保存的昵称与心情。

当前本地预览使用 `http://localhost:8081/`。若关闭开发服务或重启电脑，重新启动服务后刷新预览：

```powershell
npm.cmd run web -- --localhost --port 8081
```

这条命令只监听当前电脑的本地地址。安卓真机通过 Wi-Fi 验收时，先停止该服务，再使用下文的 `npm.cmd start`。

后续新增功能继续写在共享代码中，并同步到预览，检查实际点击、界面显示和浏览器运行错误。浏览器与安卓手机分别在自己的环境中保存数据，没有云端同步；浏览器记录不会自动出现在手机上。安卓返回键、原生存储、触觉和系统设置仍需在 Android 上验证。

## 在安卓手机上预览

电脑需要 Node.js 22.13 或更新的兼容 LTS 版本。本项目基于官方 Expo SDK 57 TypeScript 空白模板，使用 npm 管理依赖。

1. 在安卓手机安装与 SDK 57 兼容的 Expo Go，可从 [Expo 官方下载页](https://expo.dev/go) 获取。
2. 手机与电脑连接到同一个 Wi-Fi。
3. 在本 README 所在的项目根目录打开 PowerShell。
4. 首次获取项目时安装依赖：

   ```powershell
   npm.cmd ci
   ```

5. 启动开发服务：

   ```powershell
   npm.cmd start
   ```

6. 在 Expo Go 中扫描终端二维码。不要用微信扫码。
7. 初次打开应显示昵称设置，填写并保存后进入首页；以后打开应直接恢复昵称。首页显示情绪星球与五种心情选择，左上角为昵称，没有右上角日期，底部为“今天 / 轨迹 / 日历 / 统计”。点选心情，确认保存反馈、轨迹、日历和统计一致，再关闭并重新打开项目检查昵称与记录保留。

按 `Ctrl+C` 停止开发服务。修改代码后，开发服务通常会自动更新手机中的页面。

### 连接问题

- 如果扫码后连接超时，先确认同一 Wi-Fi、没有使用隔离客户端的访客网络，并按 Windows 提示允许 Node.js 在当前私人网络通信。
- 如果提示 SDK 不兼容，核对手机 Expo Go 是否支持 SDK 57，不要直接单独升级 React Native 或删除锁文件。
- 同一网络仍不能连通时，可以使用 `npm.cmd start -- --tunnel`。Expo 可能提示安装隧道工具，且需要联网；隧道速度通常比局域网慢。
- `npm.cmd run android` 适合已安装 Android SDK、配置好模拟器或 ADB 的电脑。只用手机扫码时不需要运行它。

启动链路为 `index.ts → App.tsx → NicknameProvider → 首次取名或 AppNavigator → 当前页面`。React Native 描述手机界面，React Navigation 负责导航；React 自带的 Context 和 `useSyncExternalStore` 共享记录，没有增加状态管理框架。

点选心情后，`MoodRecordsContext` 重新获取本地日期，交给 `MoodPersistence` 更新共享记录。界面先显示最新选择，存储控制器串行写入，只有最新一次写入成功才显示已经记录。快速点选时，旧写入不会把保存状态或记录恢复成旧选择。

本地数据通过 AsyncStorage 写入 `@app/mood-records/v1`，格式为 `{ version: 1, records: [...] }`。读取时校验日期、心情、ISO 创建时间和重复日期；数据损坏或版本不兼容时显示读取错误并允许重试，避免静默当作空记录。保存失败时保留最新内存记录，可重试，也可重新选择。

记录字段为 `date`（设备本地日期）、`mood`（五种可选心情，并兼容旧“普通”和“充满动力”记录）和 `createdAt`（首次创建的 ISO 时间）。按本地日期归档，避免直接截取 UTC 时间造成凌晨归档错误；恢复前台或跨午夜时刷新当天日期。

新增依赖均用于当前功能：`@react-native-async-storage/async-storage` 2.2.0 负责存储，`expo-linear-gradient` ~57.0.2 负责渐变，`expo-haptics` ~57.0.3 负责 Android 触觉。动画使用 React Native 自带的 `Animated`，没有加入 Lottie、Rive 或额外动画框架。

原先的小程序源码和项目配置已移除。已有的空 `miniprogram` 目录保留，不参与 App 运行；工作区文件夹名不影响手机 App 类型。
