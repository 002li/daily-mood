尺寸微调：`src/screens/LiuliMotionPreview.tsx` 将主星球设为舞台尺寸的 92%，给主体增加一些留白。四种心情共用此比例，舞台保留原来的占位，文字位置稳定；350 像素舞台对应 322 像素星球。类型检查通过，浏览器量测确认星球与舞台同心。此微调仅复验类型与实际预览，下方录屏和双端导出是微调前的 v3 记录；当前尺寸以交互预览为准。

## 体验入口

开发服务运行时打开 [http://localhost:8081/motion-preview](http://localhost:8081/motion-preview)。点选四种心情查看天气、轻微呼吸、按压回弹与画面淡化过渡；默认播放，已移除“静态查看”“减少动态”和播放状态文字。系统本身开启减少动态或应用进入后台时自动停止循环，不增加额外界面操作。通过“打开 App”进入根地址的正式 App。

此页面不读取或写入昵称与心情记录。预览入口在 `App.tsx` 的两个存储 Provider 之前分支，不以使用不同路径代替数据隔离。原版首页、轨迹、日历、统计与存储保持原有实现。

Android 开发环境可通过 `EXPO_PUBLIC_MOTION_PREVIEW=1` 选择此样板入口；这只是开发入口，本轮尚未在 Android 真机上验收。

## 动效设计

| 心情 | 天气与材质识别 | 动态表现 |
| --- | --- | --- |
| 开心 | 蜜金阳光、琉璃河谷 | 太阳明暗和光芒摆动，河谷光点沿水流移动，三只小鸟横穿天空 |
| 平静 | 青绿色琉璃、安静水面 | 四道可见涟漪错开扩大，增强线宽和明暗 |
| 低落 | 蓝色云雨、冷色水面 | 22 道带亮端的长雨丝持续下落，增加落水涟漪 |
| 疲惫 | 淡紫月色与浓雾 | 三层相向漂移的浓雾、月光呼吸与缓慢明灭的星光 |

星球与小选项采用轻微压扁、拉伸后回弹的软胶触感。切换时最多保留两层星球淡化，连续操作最终落在最新选择，不累计多个残留画面。返回前台不会补播先前的按压反馈。

旧版直接将图集四等分，四格内的图形位置和留白不同，导致切换时错位。修订版根据透明图形的实际边界分别取景，保留少量边缘余量，按同一中心与最大直径显示；主图和小选项共用规则。另清除了疲惫图形顶部混入的相邻图块。星球共用不中断的呼吸相位，切换不会重置呼吸位置。

这是透明位图与独立动画层组成的二维样板。呼吸、位移、缩放和淡化可用于判断动效风格；它没有真实三维模型，也未实现绕行镜头或星球背面的空间关系。

## 修改文件与原因

| 文件 | 用途与设计原因 |
| --- | --- |
| `assets/liuli/weather-atlas.png` | 保存四格透明图集，让主星球与四个选项复用同一组已确认形象。 |
| `src/components/liuli/LiuliArt.tsx` | 集中定义四种心情及各自实际图形边界，统一主图与小选项的中心和显示直径。 |
| `src/components/liuli/LiuliWeatherEffects.tsx` | 将晴光、飞鸟、水波、雨丝与雾独立于底图；后台、系统减少动态、切换和卸载时清理循环。 |
| `src/components/liuli/LiuliPlanet.tsx` | 负责星球呼吸、软胶回弹与淡化交接，处理快速操作和旧动画回调。 |
| `src/screens/LiuliMotionPreview.tsx` | 提供四选项与返回入口；移除额外动静态控件，释放空间给主星球，所有预览选择仅保存在页面内存中。 |
| `App.tsx` | 在存储 Provider 之前增加独立预览分支，供 Web 和开发环境查看，保留原版入口。 |
| `README.md`、本文档 | 登记预览地址、阶段范围与实际验收边界。 |

本阶段没有新增依赖，没有更改正式心情记录的数据结构，也没有将旧版保存的心情迁移为四种。

透明图集由已确认的 v3 模板整理而来，去掉背景、文字与固定雨线，保留山川和天气物件；制作提示词见 [atlas-prompt.txt](atlas-prompt.txt)。雨丝由代码独立绘制，让下落速度和静态显示可以控制。
